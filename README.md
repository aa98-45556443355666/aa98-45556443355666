## 🚀 Featured Project

### E-commerce Sales & Customer Analytics

[![GitHub Repository](https://img.shields.io/badge/View%20Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/aa98-45556443355666/ecommerce-sales-and-customer-analytics)

**Technologies:** Python · SQL · PostgreSQL · Apache Airflow · Docker · PySpark · Power BI · GitHub Actions

Developed an end-to-end data engineering pipeline to process e-commerce data and generate analytical datasets.

**Key Implementations:**

- **Data Ingestion:** Developed Python-based CSV ingestion workflows with SHA-256 file hashing to identify changed files and skip unchanged source files.
- **Data Transformation:** Implemented staging, clean, and warehouse layers using PostgreSQL and SQL.
- **Data Warehousing:** Designed a star-schema data model to support analytical queries and reporting.
- **Data Quality:** Implemented automated validation checks for missing values, duplicate records, and referential integrity.
- **Workflow Orchestration:** Orchestrated an 8-task ETL pipeline using Apache Airflow and Docker.
- **Big Data Processing:** Used PySpark for data processing and sales aggregation.
- **Business Analytics:** Developed SQL analytical views and Power BI-ready datasets for sales, customer segmentation, product performance, regional trends, and returns.
- **CI & Testing:** Integrated GitHub Actions and Pytest for automated code compilation and testing.
